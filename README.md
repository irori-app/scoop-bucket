# Irori for Scoop

[Irori](https://irori.app) is a fast, native game launcher for Linux, macOS and Windows.

```powershell
scoop bucket add irori https://github.com/irori-app/scoop-bucket
scoop install irori
```

The manifest is updated automatically for every Irori release by the
[publish workflow](https://github.com/irori-app/irori/blob/main/.github/workflows/publish.yml).
Report problems in the [Irori repository](https://github.com/irori-app/irori/issues).
